# Development
Run all application, dependency, build and test commands through root Docker Compose. Do not use worktrees. Keep reusable image storage, member validation, HTTP routes and native-style Admin UI in this plugin; merchant data/population and storefront code belong to the consuming application. Preserve the compatible collection schema and existing selected URLs; never delete shared media. Require authenticated native staff and enforce configured RBAC resources. Do not add uploads, URL/alt-text editors, thumbnail designation, reload controls or runtime fallbacks. Use public Medusa extension APIs. Maintain 100% per-file unit/component logic coverage; generated migrations are excluded. Validate normal locked install, plugin build/exports, consuming native build and affected browser journeys. Feature work uses a branch and draft PR; users merge. Never commit credentials, backups or catalog exports.
